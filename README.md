# Story of a Reader
A Business Intelligence project focused on exploring and analyzing personal reading habits through SQL, PostgreSQL, dimensional modeling, Power BI, and Python.

## Goals
* Learn dimensional modeling
* Learn star schemas
* Build PowerBI reports
* Analyze reading habits
* Develop BI portfolio projects
* Achieve the [PL-300 Microsoft Certified: Power BI Data Analyst Associate](https://learn.microsoft.com/en-us/credentials/certifications/data-analyst-associate/?practice-assessment-type=certification)
